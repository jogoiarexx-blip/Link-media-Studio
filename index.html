Por que links do YouTube não funcionam diretamente?

O GitHub Pages publica arquivos estáticos. O navegador não tem acesso aos fluxos privados das plataformas nem pode contornar CORS. Para baixar por URL de páginas de streaming, seria necessário conectar um backend autorizado. Esta versão não simula downloads que não pode realizar.
